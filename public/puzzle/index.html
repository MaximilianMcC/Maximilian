Kia ora. This is a puzzle I've made. I'm not sure how many people are going to participate and there is no prize for winning, but at uni we had a lecture about args and I wanted to make one so I've made one.

I plan for there to be no hints given, but you may still ask if you get stuck. If I get like a thousand dms then I'll drop a hint or two maybe but we'll see.

To play, you've got to write your answer in the URL. For example, if the first question was "What's my name" you would submit with maximilian.co.nz/puzzle/max. Answers stack too, so if question two was "where am I from" it would be maximilian.co.nz/puzzle/max/nz since I'm from nz.

The puzzle may have you going to other websites, but it will never touch anything on my website that hasn't got /puzzle/ in the URL. You are allowed to inspect element, but you are forbidden from sending automated GET requests or whatever. If the website goes down then that is not a part of the test that's just my dodgy hosting (please ping me)
